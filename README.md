# Nicholas Fasching's Personal Website

This is the Git repo of the personal [website of Nicholas Fasching](https://njf.dev), which should contain most of what you should know about him!

If you would like to run this project locally, you can run:
```bash
yarn dev
```

This website is powered by *Vercel*, *Next.js*, and *Tailwind CSS*.
